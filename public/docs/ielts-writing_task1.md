## 📊 IELTS Task 1: Describing Data & Trends

### 1. Sentence Linkers
Use these to connect ideas and ensure logical flow. They are often followed by a comma.

| Category       | Linkers                                                                                                                        | Translation (IT)                                            | Example                                                          |
| :------------- | :----------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------- | :--------------------------------------------------------------- |
| **Contrast**   | Although, However, Conversely, Despite, In contrast, Instead, Nevertheless, On the contrary, On the other hand, Whereas, While | Sebbene, Tuttavia, Al contrario, Nonostante, Invece, Mentre | *The first two services are free, while the third costs £35.00.* |
| **Similarity** | Likewise, Similarly, In the same way                                                                                           | Allo stesso modo, Similmente                                | *The US won the track events. Similarly, they led in swimming.*  |
| **Result**     | Therefore, Thus, Hence, As a result, Consequently, Accordingly                                                                 | Pertanto, Quindi, Di conseguenza                            | *Profits fell; consequently, the company restructured.*          |
| **Sequencing** | Firstly, Secondly, Thirdly, Subsequently, Moreover, Furthermore, In addition, Last/Lastly                                      | In primo luogo, Poi, Inoltre, Infine                        | *Firstly, it’s expensive; secondly, it’s too slow.*              |
| **Examples**   | For example, For instance                                                                                                      | Per esempio                                                 | *Take precautions, for instance, checking desk height.*          |

---

### 2. Verbs for Describing Data
Use these to introduce charts and describe specific information.

| Verb                    | Meaning (IT)              | Example                                               |
| :---------------------- | :------------------------ | :---------------------------------------------------- |
| **Provide info about**  | Fornire informazioni      | *The table provides information about food spending.* |
| **Analyze**             | Analizzare                | *This book teaches you how to analyse stress.*        |
| **Compare / Contrast**  | Confrontare / Contrastare | *She contrasted the past situation with the crisis.*  |
| **Depict / Illustrate** | Raffigurare / Illustrare  | *The chart depicts the number of policy changes.*     |
| **Outline / Delineate** | Delineare                 | *The relationship was delineated in the agreement.*   |
| **Highlight**           | Evidenziare               | *The report highlights the recent tensions.*          |
| **Represent / Show**    | Rappresentare / Mostrare  | *The diagram represents the life cycle of a frog.*    |

---

### 3. Adjectives & Adverbs (Trends)
Combine these to describe the speed and size of changes.

| Intensity       | Adjectives                                  | Adverbs                                 |
| :-------------- | :------------------------------------------ | :-------------------------------------- |
| **Strong/Fast** | Sharp, Dramatic, Significant, Substantial   | Sharply, Dramatically, Significantly    |
| **Moderate**    | Moderate, Consistent, Steady                | Moderately, Steadily, Constantly        |
| **Small/Slow**  | Gradual, Slow, Slight, Marginal, Negligible | Gradually, Slowly, Slightly, Marginally |
| **Irregular**   | Intermittent, Sporadic                      | Intermittently, Sporadically            |

---

### 4. Vocabulary for Movement

| Direction       | Verbs                                                              | Nouns                                                  |
| :-------------- | :----------------------------------------------------------------- | :----------------------------------------------------- |
| **Increase**    | Rise, Grow, Go up, Improve, Soar, Skyrocket, Surge, Double, Triple | A rise, An increase, A growth, An improvement, A surge |
| **Decrease**    | Fall, Decline, Drop, Go down, Plummet, Slump, Dip, Halve           | A fall, A decline, A drop, A reduction, A dip          |
| **No Change**   | Remain stable/constant, Level out, Reach a plateau, Be unchanged   | Stability, A plateau, A stabilization                  |
| **Fluctuation** | Fluctuate, Change intermittently, Rise and fall                    | A fluctuation, Variations                              |

---

### 5. Proportions & Fractions
Avoid repeating percentages; use these descriptive alternatives.

| Percentage    | Fraction / Proportion                                    |
| :------------ | :------------------------------------------------------- |
| **75% / 77%** | Nearly three quarters / Approximately three quarters     |
| **51% / 49%** | Just over a half / Around a half / Just under a half     |
| **32% / 33%** | Nearly a third                                           |
| **25% / 24%** | A quarter / Almost a quarter                             |
| **71% / 70%** | A significant majority / A large number                  |
| **3% - 15%**  | A negligible minority / A small minority / A tiny amount |
